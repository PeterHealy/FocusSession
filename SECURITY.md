# Security policy

FocusSession is a local focus aid, not a tamper-proof or parental-control
security boundary. Its documented bypasses include ending a session early,
stopping the app, disabling the extension, using another browser, and changing
the system clock.

## Reporting a vulnerability

Please do not publish an issue containing a working exploit, private browsing
data, local file paths, or other personal information.

Until a private security contact is published for this project, share only a
minimal, redacted report with the repository owner through a private channel.
Include the affected version, expected and actual behavior, impact, and the
smallest reproduction that does not contain personal data.

Ordinary bugs and feature requests can use the public issue tracker.

## Supported versions

The project is currently a development v1. Only the latest revision is
maintained; there are no separately supported release branches yet.
